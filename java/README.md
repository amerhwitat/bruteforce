# Java implementation

Java 21 research and GUI layer for the cross-language Chimera crypto/AI benchmark suite. Java modules consume the same deterministic vectors and public/synthetic datasets as Python.


## Maintained Java source

The `src/main/java` tree contains `Hashing`, `SyntheticBenchmark` and `ResearchCli`; tests are under `src/test/java`. See [module README](README.md) for Maven commands.
