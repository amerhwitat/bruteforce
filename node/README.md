# Node.js implementation

This directory is the Node.js ESM integration track for the repository. It mirrors the safe Python research scope: deterministic key-to-address demonstrations, address validation, public/synthetic cryptographic vectors, audit/provenance and Chimera II interoperability.

It does not implement address-to-private-key recovery, seed guessing, credential attacks, or unauthorized wallet access.

See the root README and `docs/CRYPTO_AI_BOUNDARY.md` for the security boundary.
