# Linux Commands Source Integration

Reference profile: GNU Coreutils, util-linux, iproute2/net-tools, sudo, POSIX shells, and Toybox. Preserve upstream licenses/SPDX metadata and integrate through adapters.

Performance policy: bounded concurrency is allowed for benign independent workloads, but this repository is not extended with credential/private-key brute-force acceleration. Preserve rate limits, auditing, and safe test modes.

Canonical Chimera II integration is maintained in `amerhwitat/ChimeraIIOS`.
