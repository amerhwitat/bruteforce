# Cross-language implementation

Python remains the reference research layer. Node.js is the ESM integration layer. Java and C++ are interoperability/native tracks. Shared JSON/JSONL contracts and deterministic public/synthetic vectors define compatibility.

The security boundary is identical in every language: restore-and-verify from recovery material already possessed is allowed; address-to-private-key recovery, seed guessing, arbitrary key enumeration, credential attacks and unauthorized wallet access are not.
