# Chimera 128D + P2P Portfolio Integration

The repository uses the Chimera multidimensional profile for public/synthetic research metadata only. Workload state may include geometry/topology, time, observer perspective, events, objects, properties and extensible analytical vectors.

P2P is opt-in and authenticated. Nodes validate identity/capabilities, sequence/replay state, payload hashes and optional signatures before exchanging deterministic research records.

The protocol does not distribute private keys or seed phrases, coordinate unauthorized cracking, perform unsolicited network scanning, transfer arbitrary executables or execute remote commands.

Python, Node.js, Java and C++ tracks consume shared JSON/JSONL conformance vectors.
